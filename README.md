# adventes-bingo
Autentiskais Adventas Bingo ir digitāls interaktīvs kalendārs, kura mērķis ir mazāk screen time, vairāk real moments. Prieks kā izvēle, nevis pienākums. Šiet ir iekļauti 24 uzdevumi BEZ datumiem - tu izvēlies pēc mood. Nav "nokavēju dienu" guilt. Perfekti derēs tev, ja esi aizmirsis vai nezini kā radīt jēgpilnus un klātesošus mirkļus
